# Adani Gas Stock Price Analysis using R Studio

## Project Overview
This project performs a complete financial and stock market analysis of Adani Total Gas Limited (ATGL.NS) using R Studio.

The project includes:

- Financial Data Acquisition
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Advanced Data Visualization
- Time Series Analysis
- ARIMA Forecasting
- Algorithmic Trading Strategies
- Technical Indicators
- Performance Evaluation

---

## Objective

To analyze historical stock data of Adani Total Gas and apply forecasting and trading techniques to understand market behavior and generate investment insights.
